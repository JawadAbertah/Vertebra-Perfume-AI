# 🌟 AAA Luxury Perfume Bot API

Backend for customer service and order management. Built with FastAPI, MongoDB, and Gemini AI.

## 🚀 Tech Stack
* **FastAPI** (Python 3.9)
* **Google Gemini 3.1-flash-lite** (RAG via LangChain)
* **MongoDB Atlas & Motor** (Async Database)

## ⚙️ Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Add `.env` file with `GOOGLE_API_KEY`, `GOOGLE_MODEL`, and `MONGO_URI`.
3. Run the server: `python -m uvicorn main:app --reload`# Vertebra-Perfume-AI
